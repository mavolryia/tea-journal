# Tea Journal 🍵

Личная чайная коллекция и дневник дегустаций проливами. Работает в браузере, ставится на телефон
как приложение (PWA), хранит всё на самом устройстве — сервер не нужен.

## Что умеет (версия 0.1)

- **Коллекция**: тип, регион, год, производитель, остаток в граммах, избранное, поиск и фильтр по типу.
- **Дегустация**: способ заваривания, граммы/мл (считает соотношение 1:N), вода, посуда,
  аромат сухого и прогретого листа, вкус, текстура, послевкусие, свободный комментарий.
- **Проливы**: у каждого своя температура, время и заметка. Встроенный таймер:
  если время задано — обратный отсчёт со звуком и вибрацией, если нет — секундомер,
  и фактическое время записывается в пролив. Экран не гаснет, пока таймер идёт.
- **Голос**: кнопка 🎤 у каждого текстового поля (русский язык). Если браузер её не
  поддерживает — подойдёт микрофон на клавиатуре телефона.
- **Дескрипторы**: готовые группы (цветочные, древесные, землистые…) + свои.
- **Оценки** листиками 1–5: аромат, вкус, послевкусие, общая.
- **«Заварить так же ещё раз»** — новая запись с теми же параметрами проливов.
- **Сравнение** двух дегустаций рядом (общие дескрипторы подсвечены).
- **Списание остатка** при сохранении дегустации.
- **Черновик** новой записи сохраняется автоматически — не потеряется при перезагрузке.
- **Статистика** и **резервная копия** в JSON (сохранить / загрузить) — вкладка «Ещё».
- Светлая и тёмная тема (по настройке телефона).

## Как запустить на компьютере

Нужен Node.js (уже установлен). В папке проекта:

```bash
npm install
npm run dev
```

Откроется адрес http://localhost:5173.

## Как поставить на телефон

Голосовой ввод и установка как приложения требуют **HTTPS**, поэтому самый простой путь —
бесплатный хостинг GitHub Pages:

1. Создать репозиторий на GitHub и загрузить туда проект.
2. `npm run build` → появится папка `dist` — это готовый сайт.
3. Опубликовать `dist` на GitHub Pages (можно настроить автоматически через GitHub Actions).
4. Открыть ссылку на телефоне:
   - **Android (Chrome)**: меню ⋮ → «Добавить на главный экран»;
   - **iPhone (Safari)**: «Поделиться» → «На экран „Домой“».

> Данные живут в браузере конкретного устройства. На телефоне и компьютере будут разные
> дневники — переносите их через «Ещё → Сохранить копию / Загрузить из файла».

## Устройство проекта

```
src/
  types.ts          модель данных, справочники (типы чая, способы, дескрипторы)
  db.ts             работа с IndexedDB, экспорт/импорт, проверка файла копии
  data.tsx          общее состояние приложения
  utils.ts          роутер на #hash, форматирование, localStorage
  components/ui.tsx голосовое поле, таймер, оценка, выбор дескрипторов
  screens/          экраны: коллекция, дегустации, сравнение, «Ещё»
public/
  manifest.webmanifest, sw.js, иконки — всё для PWA
```

## Идеи для QA-практики

- Граничные значения: 0 г, отрицательный остаток, очень длинные названия, 30 проливов.
- Импорт: пустой файл, чужой JSON, повреждённая запись, «добавить» vs «заменить».
- Офлайн: собрать (`npm run build && npm run preview`), открыть, выключить сеть.
- Черновик: начать запись, перезагрузить страницу, проверить восстановление.
- Автотесты: Vitest для `db.ts`/`utils.ts`, Playwright для пользовательских сценариев.
